3. FEATURE REQUIREMENTS
-------------------------------------------------------
===========================
Feature 1 — Auto-Follow-Up Engine
===========================
Purpose:

Reduce lost leads by automatically surfacing or sending follow-up messages when buyer goes silent.

Functional Requirements:
1.1 Lead Inactivity Detection

Track last inbound message timestamp

Track last outbound message timestamp

If no reply for X hours (default: 12h), mark conversation as Needs Follow-Up

1.2 Auto-Suggestion UI

When a thread is marked “Needs Follow-Up,” show a banner:
“Buyer inactive for X hours — Suggest follow-up?”

Display 3 AI-generated follow-up messages

User can tap to send instantly

1.3 Auto-Send Mode

Toggle per conversation:
[ ] Auto-send follow-ups if buyer doesn’t reply within X hours

If ON → send one AI-generated follow-up

Log the message in conversation

1.4 Avoid Spam Logic

Only 1 auto-follow-up per 48 hours

Never auto-follow-up twice in a row

If user manually replies, reset the timer

Technical Requirements:

Add last_agent_message_at and last_buyer_message_at fields

Add needs_follow_up boolean

Add auto_follow_up_enabled boolean

Backend cron job (or event loop) checks inactivity every 5 min

AI prompt for generating follow-ups uses last 5 messages context

===========================
Feature 2 — Auto-Info Pack Quick Replies
===========================
Purpose:

Eliminate repetitive responses to common buyer questions.

Functional Requirements:
2.1 FAQ Detection

When a buyer message contains keywords:

Price-related

“price”, “guide”, “how much”, “budget”

Inspection-related

“when inspect”, “inspection”, “open home”

Property info

“strata”, “fees”, “body corp”, “contract”, “address”

“floorplan”, “photos”, “details”

→ Trigger Quick Reply Buttons
2.2 Listing Info Form

User can enter core listing data:

Price guide

Address

Inspection times

Strata fee

Contract link

Info pack link

Floorplan URL

Agent name + mobile

Stored per-listing with ID.

2.3 Quick Reply Buttons in UI

Buttons appear above your existing 3 reply suggestions.

Example:
[Price Guide] [Full Info Pack] [Inspection Times]

Tapping sends a preformatted message with listing info.

Technical Requirements:

Add listing schema

Associate conversations with listing

FAQ keyword matcher

Message-template generator

Prebuilt templates for price, info pack, inspection, etc.

===========================
Feature 3 — AI Conversation Summary
===========================
Purpose:

Instant context recall + mental load reduction for the agent.

Functional Requirements:
3.1 AI Summary Generation

Every conversation gets a summary:

Buyer name (if extractable)

What they want (bed, location type)

Budget

Key questions asked

Lead intent (hot/warm/cold using scoring)

Action needed (follow-up? send doc?)

3.2 Summary Panel UI

Displayed on sidebar or top:

Buyer Summary
-------------
Name: John
Budget: $1.1m
Asked for: strata, inspection time
Lead Score: Hot
Pending: Send contract
Last Touch: 14 hours ago

3.3 Lead Scoring

Simple scoring rules:

Replies fast = +1

Asked for contract = +2

Asked multiple questions = +1

Attended inspection (entered manually later) = +3

Technical Requirements:

Add summary field for each thread

Add lead_score

Use prompt template: “Summarize conversation in structured JSON: {budget, intent, questions, next_steps, score}”

Update summary every new message

===========================
Feature 4 — Daily “Action Dashboard”
===========================

(This is optional but extremely powerful)

Purpose:

Show agent exactly who they need to speak to.

Functional Requirements:

Dashboard Sections:

A. Needs Follow-Up (inactive > 12h)
B. Hot Leads
C. Unread Messages
D. Waiting For Documents (AI detects “send me”, “can I get”, etc.)
E. Today’s Inspections (manual entry for now)

Each row:

Buyer name

Summary snippet

Last activity

One-click “Send Follow-Up” button

Technical Requirements:

One API endpoint: /dashboard

Query against conversation states

Return JSON for the frontend to render
